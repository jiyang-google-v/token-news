# SOL 外盘雷达自动采集

网站：https://sol-migration-radar.plumbean16.chatgpt.site

本任务独立于海外新闻任务，仅读写 `data/sol-radar/latest.json`。只保存公开代币信息，不使用网站密钥或个人访问令牌。

- GitHub Actions 每 5 分钟调度一次（每小时 02、07、12…57 分钟），可能排队延迟。
- 距上次新币发现满 30 分钟时，扫描最近 30 小时内的 pump.fun 已迁移代币并核验最多 40 个待核验对象；已有重点目标优先。
- 其他轮次仅刷新重点跟踪目标，用迁移年龄窄窗口批量匹配地址。此时不设置 holdersMin，才能观察持有人跌破 50。响应缺失、饱和或失败会明确记录；绝不把旧数据盖成新时间。
- 首次核验迁移后美元历史；通过后增量回查尚未闭合的 5 分钟区间。缺口或接口失败不能证明历史未触顶，相关对象保持待核验。
- 当前持有人 <50，或当前价 <0.000003 美元，或当前/已知迁移后最高价 >=0.0008 美元退出重点更新。历史触顶保留，回落不重入。满 30 小时退出监控。
- 每轮只写一份最新 JSON，由 GitHub 自动提供的 GITHUB_TOKEN 提交（contents: write）。无新币发现周期仍保留未更新对象的原快照时间。
- 网站每分钟读取最新仓库快照并合入已有 D1；页面关闭时 Actions 仍持续采集并保存，下一次访问会读取新结果。GitHub CDN 可能额外延迟，以实际采集时间为准。超过 10 分钟未更新会显示延迟提示。
- 部分来源失败会在 Actions 摘要和网站状态中展示。全部列表请求失败不覆盖文件。并发新闻提交使用 rebase 合并独立文件，不强推。

手动运行：Actions → “SOL 外盘雷达 · 5分钟重点池更新” → Run workflow。可勾选强制发现新币。

本地验证：

```sh
python -m unittest discover -s tests -p 'test_sol_radar.py'
python scripts/sol_radar/run.py
```

边界：Binance 已收录范围，不保证全链完整；5分钟并非实时，1分钟突破捕捉仍需更高频行情。逐笔最高价、关联钱包和社区真实性未获独立核实。
